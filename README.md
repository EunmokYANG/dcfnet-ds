# DCFNet-DS

An intrusion detector whose class logits separate exactly into homogeneous
polynomial terms, one per degree,

```
logit_c(x) = phi_1,c(x) + ... + phi_K,c(x) + b_c
```

as an identity rather than as a post-hoc approximation. This repository holds
the code and the result tables for two companion papers that share it.

| Paper | Question | Reproduce with |
| --- | --- | --- |
| **Feature Scaling Determines What Arithmetic-Combination Intrusion Detectors Can Learn: The Limits of Affine Normalization**<br>E. Yang, S. Choi, C. Seo. Submitted to *IEEE Access*. | What does the choice of input scaling decide, and what can it not change? | [`REPRODUCE_paper1_scaling.md`](REPRODUCE_paper1_scaling.md) |
| **Polynomial-Degree Decomposition of a Network Intrusion Detector: Exactness and the Accuracy–Auditability Trade-off**<br>E. Yang, Y. Jeong, C. Seo. Submitted to *IEEE Access*. | How far up the degree hierarchy does detection reach, and what does exact decomposability cost? | [`REPRODUCE_paper2_degree.md`](REPRODUCE_paper2_degree.md) |

Each of the two files above is self-contained: datasets, environment, the
commands in order, and where every table and figure of that paper comes from.
Read the one for the paper you are interested in; you do not need the other.

The two papers vary different things. Paper 1 varies the input scaling and
holds the degree fixed at K = 4; paper 2 fixes the scaling at signed-log and
varies the degree. Their experiments write into the same tables under
different tags, which §*Tags* of each file explains.

## Repository layout

```
src/                    all code
  config.py             paths, datasets, hyperparameters, variant definitions
  prepare_data.py       source CSV -> raw CSV
  preprocess.py         scaling, splitting, identifier removal -> npz
  model.py              DCFNet-DS and the baselines
  train.py              one run
  multiseed.py          repeated runs, merged into seeds_*.csv
  sweep.py              condition sweeps (degree, scaler, split, amplify)
  baselines.py          logistic regression, random forest, HistGradientBoosting
  evaluate.py           metrics
  degree_analysis.py    per-degree contributions, identity and homogeneity
  perturbation.py       selectivity test for the recovered combinations
  compare.py            pairwise tests over the seed table
  p1_figures_v1.py      every figure and table of paper 1
  p2_figures_v2.py      figures of paper 2
  p2_coeff_attribution_v1.py   closed-form monomial coefficients
  p2_arity_v1.py        interaction arity within each degree
  p2_paired_stats_v1.py paired significance tests
  p2_verify_numbers_v1.py      seed counts and single comparisons
data/                   not tracked; each paper's file says what to download
outputs/
  tables/               shared experiment tables
    paper1_scaler/      paper 1 tables
  figures/
    paper1_scaler/      paper 1 figures
  paper2_degree/
    tables/             paper 2 tables
    figures/            paper 2 figures
  models/               not tracked; regenerated by the commands in each file
```

The trained checkpoints are not included: several hundred files that no
analysis needs and that the commands regenerate.
